Formatting and table tools

  • RM format: select a numeric cell and tap RM format to display values such as RM 300.00. The number remains usable in calculations.
  • Merged cells: select the first cell, tap Merge cells, then tap the opposite corner. Select a merged cell and tap Unmerge to separate it.
  • Cell size: use Cell size on iPhone. On a computer, you can also drag a column or row edge.
  • Formula editing: select a calculated cell to view or change its original formula in the formula bar.
  • Dashboard links: linked Home values update automatically when the selected budget data changes.
