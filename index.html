OFFLINE JAVASCRIPT SHEET

Spreadsheet Information

Local and private

This spreadsheet runs with JavaScript in Pocket Budget and is saved in the same local IndexedDB database. It does not open or upload data to Google Sheets, Excel, or OneDrive. Spreadsheet data is included in your encrypted .pbe backup.

How to use it

  • Select: tap a cell once. The keyboard stays closed, making the sheet easier to scroll on a phone.
  • Select a range: tap Range, then tap the opposite corner. On a computer, Shift+click or Shift+Arrow also extends the selection.
  • View / Edit mode: the sheet opens in view-only mode. Tap Edit before changing any cell. Tap Editing again to lock the sheet back to view-only mode.
  • Zoom: pinch with two fingers directly over the sheet to zoom from 65% to 160%.
  • Navigate: on a computer use Arrow keys, Tab, Enter, Delete, Ctrl/Cmd+C, and Ctrl/Cmd+V.
  • Focus mode: expands the spreadsheet. In landscape, the title/description/status text is removed and Exit moves into the icon toolbar.
  • Copy and paste: supports selected ranges and tab-separated rows copied from another spreadsheet.

Use Add row and Add column to expand the workbook. Existing V28 sheet cells are kept automatically.

Formatting and table tools

  • RM format: shows a number as RM 300.00 while keeping it available for calculations.
  • Alignment: select one cell or a range and tap Align to cycle Auto → Left → Center → Right.
  • Font size: select cells, tap Font size, then choose 10–28 px. Reset returns to the default size.
  • Merged cells: select a range and tap Merge, or use the original first-corner/opposite-corner flow. Select a merged cell and tap Unmerge to separate it.
  • Cell size: use Cell size on a phone. On a computer, drag a row or column edge.
  • Dashboard links: place Total income, Expenses, Saved, or Available balance in any valid cell.
  • Undo and redo: available during the current app session.
