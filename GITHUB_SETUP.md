# Publish Pocket Budget Version 31

1. Extract the V31 ZIP.
2. Upload the files inside the project folder to the GitHub repository root. `index.html` must be at the root.
3. In GitHub open **Settings > Pages**.
4. Choose **Deploy from a branch**, `main`, `/ (root)`.
5. Wait for deployment and open the Pages URL.
6. On iPhone/Android, fully close the installed PWA and reopen it after the update.

V31 cache name:

```text
pocket-budget-v31-advanced-offline-sheet
```

For local testing:

```text
http://localhost:8000/?v=31&view=sheet
```
